Student Marks Statistical Analysis using NumPy

Project Description

This project uses Python and NumPy to analyse the marks of students. It calculates the average, median, highest marks, lowest marks, and standard deviation. This helps us understand student performance in a simple way.

Objective

The main objective of this project is to learn how NumPy can be used to perform basic statistical calculations on numerical data.

Technologies Used

- Python
- NumPy
- Jupyter Notebook

Dataset

The project uses marks of 10 students:

"78, 85, 90, 67, 92, 75, 88, 80, 95, 70"

Features

- Stores student marks in a NumPy array.
- Calculates the average marks.
- Finds the median value.
- Identifies the highest and lowest marks.
- Calculates the standard deviation.
- Displays the results with a short explanation.

Output

- Average Marks: 82.0
- Median Marks: 82.5
- Highest Marks: 95
- Lowest Marks: 67
- Standard Deviation: 8.68

How to Run the Project

1. Install Python on your computer.
2. Install NumPy using the command "pip install numpy".
3. Open Jupyter Notebook.
4. Copy the Python code into a notebook cell.
5. Run the cell using "Shift + Enter".
6. Check the statistical results.

What I Learned

Through this project, I learned how to create NumPy arrays and use built-in functions to calculate statistical values. I also understood how standard deviation helps measure the variation in student marks.

Conclusion

This project helped me practise Python and NumPy through a simple real-world example. It improved my understanding of numerical data analysis and basic statistics.
